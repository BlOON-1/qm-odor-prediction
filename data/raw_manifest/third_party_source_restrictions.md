# Third-Party Source Restrictions

This repository includes processed and derived materials built from multiple upstream sources. Redistribution rights do not automatically extend to raw third-party source records.

## Sources requiring caution

- The Good Scents Company: raw source records and database-style exports may be subject to provider-specific terms.
- Leffingwell: raw source records and database-style exports may be subject to provider-specific terms.
- M2OR: reuse of raw source tables should follow the original provider's terms and attribution requirements.
- PubChem: public identifiers and structures can be cited and linked, but users should still follow the original source terms and attribution guidance.

## QM workflow restriction

QM descriptor generation in the associated study relied on commercial or otherwise restricted software workflows, including Gaussian and Multiwfn. Raw QM outputs and intermediate files are therefore not included in the current public repository snapshot.

## Public release boundary for this repository

The repository is intended to distribute:

- code and configuration files for non-commercial research and educational use
- processed benchmark tables and descriptor files where redistribution is appropriate
- aggregated sensory-panel summaries
- derived receptor-consistency summaries
- manuscript-supporting source-data workbooks

The repository is not intended to redistribute:

- raw proprietary source databases
- non-anonymized sensory panel records
- commercial software binaries
- large restricted QM intermediate outputs
